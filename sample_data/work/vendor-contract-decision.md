# Decision: hosting vendor contract

Date: 2026-07-10

We renew with Acme Hosting for one year at the same rate ($2,400 per month) instead of moving to a cheaper provider.

Why:
- Migration would take about six weeks of engineering time.
- Acme agreed to a 99.95% uptime credit clause.
- We will run a proper comparison in April 2027, before the next renewal.
